# Chrome Web Store Listing — CourtVision 3.4.1

## Short description

Tag basketball game film on YouTube, create precise clips, track outcomes, and export analysis for your team.

## Detailed description

CourtVision is a Chrome desktop extension for basketball coaches and analysts.

Open a game on YouTube and tag important moments without leaving the video. CourtVision saves the clip timing locally on your laptop, so you can review, organize, and share your analysis quickly.

Features:

- One-click tagging for offense, defense, transition, set plays, BLOB, SLOB, and custom categories.
- Adjustable time before and after every tag.
- Made/missed outcome tracking.
- Clip review with precise YouTube timestamps.
- Custom team names, category names, colors, and order.
- WhatsApp sharing with a compact CourtVision clip-viewer link.
- JSON backup and restore.
- CSV, JSON, and Hudl Sportscode-compatible XML export.
- Seven-day free trial with Google sign-in.
- Optional CourtVision Pro access for 30 or 365 days through Duitku.

CourtVision currently supports Chrome desktop on Windows, macOS, and Linux. CourtVision Mobile and Hardwood are separate products and are not included.
